## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Human Farm: Investigation:**. This trainer provides convenience options for the game's exploration, timed daily routine, investigation progress, inventory management, and action segments. It is designed to reduce repetitive tasks while preserving the game's story-driven structure and branching progression.

**Target Audience:** Players who want to reduce travel and time-management pressure, complete investigation objectives more easily, experiment with inventory and suspicion values, or replay story routes and action segments with less repetition. The game is intended for adults because it contains mature themes, nudity, and sexual content.

## 📖 Detailed Feature Guide

### Movement & Exploration

Launch the game first and load a save before enabling movement-related options. Use the movement-speed control for faster travel between the underground farm, city districts, and cafe hub. The game uses keyboard-based navigation, with arrow keys for movement and Z or Enter for confirmation. Disable the option before entering menus or closing the game if movement behaves unexpectedly.

### Tools & Inventory

Activate inventory options only after loading a save and opening the in-game inventory or item-related menu. Select the item you want to modify, change its quantity, and return to gameplay to confirm the result. Quest items and evidence can affect story flags, so keep a backup save before changing or removing them.

### World & Environment

The daily loop includes farm shifts, city errands, handler meetings, evening events, and sleep-related calendar progression. Use the time and investigation options to explore locations without rushing, but avoid changing story values during active dialogue or event transitions. Save before major deadlines, evidence deliveries, and route decisions.

### Combat & Weapons

Human Farm: Investigation: is primarily a story and investigation RPG rather than a conventional combat game. Use action-segment assistance only when an active sequence or boss-related encounter is running. Do not activate unrelated options during dialogue, scene playback, or event transitions, and reload a clean save if an encounter fails to advance.
